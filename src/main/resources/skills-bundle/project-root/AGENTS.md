# Unreal Engine

This project is open in UnrealInterface. Work in this directory.

## Editor operations

Prefer Unreal MCP tools for editor operations: actors, levels, lighting, materials, Blueprints, screenshots, and Play In Editor. Edit `.uasset` or `.umap` files only when no MCP tool can do that job.

When a `.uproject` is present, follow the `unreal-router` skill before changing the game.

## Verify visually

Verify changes visually when you can. Capture the editor viewport or run Play In Editor, look at the result, and fix what you see. A successful tool result is not a visual check.

## Small tasks

Keep each task small. Change one thing, check it, then continue.
